Lightcone Research Agent Skills¶

Portable, open-standard skills that teach coding agents the Lightcone Research stack.

The skills follow the Agent Skills standard, work across Claude Code and Codex, and are packaged as plugins with their hooks included.

View on GitHub

Plugins¶

Plugin What it provides
astra ASTRA authoring guidance and validation hooks.
lightcone Companion for a whole Lightcone project — scoping, the lc execution workflow, publishing. Bundles astra, so installing it alone gives the full stack.

Install¶

The only prerequisite is uv: plugins with Python dependencies install them on first use.

claude plugin marketplace add LightconeResearch/agent-skills
claude plugin install astra@lightcone-research

Then invoke /astra:astra in a session.

Go to Customize → Plugins, click Add, then choose Add marketplace → Add from repo. Paste https://github.com/LightconeResearch/agent-skills, pick astra, and call it with /astra:astra.

codex plugin marketplace add LightconeResearch/agent-skills
codex plugin add astra@lightcone-research

Then invoke the skill in Codex, for example $astra:astra.

Click the arrow beside Create and open Plugins. Install the LightconeResearch/agent-skills marketplace, search for astra, and install it. Then call /astra:astra.
