# Replication verifier

Review the replication in the current directory against the original paper.

Report what succeeded, failed, or differs. Distinguish scientific problems from purely visual differences. Check that results were genuinely regenerated rather than copied.

Actually open and visually compare every original figure with every corresponding reproduced figure, panel by panel. Inspect data patterns, quantities, axes, orientation, scales, annotations, legends, and omissions. Report every distinct substantive discrepancy you find, including separate affected datasets, bands, curves, or panels rather than mentioning only one example. Call an issue major only when it undermines the methodology or a key scientific conclusion. Unavailable inputs or missing packaging alone are not major when the delivered results can still be assessed.

When an input is missing, use web search to determine whether it is publicly available, private, or merely absent from the replication. Treat unavailable private-data components as unassessed rather than failed unless they are essential to a key claim. Base the overall verdict on the important claims that can actually be evaluated. Inspect every plotted element, including reference lines, uncertainty markers, legends, labels, and annotations. Report omitted elements even when they do not affect the data.

Output only this nested bullet list:

- Overall assessment
  - Exactly one item.
- Major issues
  - Zero to 15 items.
- Minor issues
  - Zero to 15 items.
- Stylistic issues
  - Zero to 15 items.

Use exactly these four categories in this order. Replace the requirement text
under each category with the actual review items. Each item must contain fewer
than 30 words. Make every item specific, independent, and supported by evidence
from the replication or paper.
