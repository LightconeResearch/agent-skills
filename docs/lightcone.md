# Lightcone

The `lightcone` plugin teaches an agent the `lc` project workflow and bundles
the complete `astra` plugin.

Use `/new` to turn a research question into a structured ASTRA analysis,
`/report` to write a report that stays linked to the analysis, `/cli` for the
execution workflow, and `/feedback` to report problems to the right repository.
It also includes the session primer, validation hooks, and the paper-extraction
subagent used while scoping a new analysis.

```bash
codex plugin add lightcone@lightcone-research
```

[View the Lightcone skills on GitHub](https://github.com/LightconeResearch/agent-skills#core).
